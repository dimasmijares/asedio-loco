# Asedio Loco

Juego de navegador en 3D, multijugador en línea para hasta 4 jugadores: castillos destructibles con física real, catapultas tipo tirachinas y munición absurda (vacas explosivas, pianos, agujeros negros…). Gana el último rey en pie.
